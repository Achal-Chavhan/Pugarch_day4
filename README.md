# Pugarch_day4

Day 04 – Facility Hygiene Risk Prediction

Objective
Build a machine-learning model that predicts a facility's hygiene risk as **Low**, **Medium**, or **High** using cleanliness score, odor score, waste level, complaints, footfall, and hours since cleaning.

Dataset note:** `dataset/facility_hygiene.csv` is a synthetic practice dataset created for this assignment. It is not real inspection data, and the risk labels are simulated for learning purposes.

Features
- `cleanliness_score`: cleanliness rating from 0 to 10; higher means cleaner.
- `odor_score`: odor severity from 0 to 10.
- `waste_level`: observed waste level from 0 to 10.
- `complaints`: number of hygiene complaints.
- `footfall`: approximate number of visitors.
- `hours_since_cleaning`: hours since the last cleaning.
- `hygiene_risk`: target label (`Low`, `Medium`, or `High`).

 Workflow
1. **Dataset:** Load the facility hygiene CSV.
2. **Cleaning:** Remove duplicate rows, correct invalid score/count values, and fill missing numeric values with medians.
3. **EDA:** Run `python preprocessing/eda.py` to review summary statistics, missing values, class counts, and numeric feature histograms.
4. **Feature engineering:** Use the six requested fields as model features. The target is `hygiene_risk`.
5. **Train/test split:** Keep 80% for training and 20% for testing, using stratification and `random_state=42`.
6. **Model training:** Compare Logistic Regression (scaled features) and Random Forest.
7. **Prediction:** Predict risk labels for records in `predictions/new_facilities.csv`.
8. **Evaluation:** Compare accuracy, macro precision, macro recall, and macro F1-score. Macro F1 is used to select the model because it gives equal weight to each risk class.

Setup and run
Use Python 3.10 or newer. From the `day-04` folder, install dependencies:

```bash
pip install pandas numpy scikit-learn matplotlib joblib
```

Run the scripts in this order:

```bash
python preprocessing/prepare_data.py
python preprocessing/eda.py
python models/train_models.py
python evaluation/evaluate_model.py
python predictions/predict_risk.py
```

Run preprocessing before training. Run training before evaluation and prediction.

Model selection and performance
The training script writes the measured test metrics to `evaluation/model_comparison.csv` and selects the model with the highest macro F1-score. Do not copy guessed scores into your report; use the actual values generated by your run. Because this is a synthetic dataset, the scores show how the workflow runs, not how well a model would perform in a real facility.

Problems encountered
- Missing values in some numeric fields.
- Invalid values such as scores outside 0–10 and negative complaint counts.
- Risk categories may not be perfectly balanced.
- A synthetic target cannot represent every real-world hygiene condition.
- Results can change with different random splits or model settings.

Possible improvements
- Collect verified inspection records and have hygiene experts label risk levels.
- Add facility type, temperature, humidity, cleaning staff, and time-of-day features.
- Use cross-validation and tune hyperparameters.
- Monitor class-level precision and recall, not only accuracy.
- Re-train periodically and check for data drift.
- Treat predictions as decision support; confirm high-risk predictions with a human inspection.

Report template
- **Selected model:** Copy the model name from `models/selected_model.txt`.
- **Features:** cleanliness_score, odor_score, waste_level, complaints, footfall, hours_since_cleaning.
- **Performance:** Report accuracy, macro precision, macro recall, and macro F1 from `evaluation/model_comparison.csv`.
- **Problems:** Missing and invalid data, possible class imbalance, and the limitations of synthetic labels.
- **Improvements:** Use real labelled data, cross-validation, tuning, additional features, and expert verification.
